# ЕГЭ Математика - Telegram-бот

Простой бот для подготовки к ЕГЭ по математике (профильный уровень).

## Что умеет

- Тренировка по номерам заданий (1-19)
- Полный вариант (по одному заданию на каждый номер)
- Проверка ответов части 1 кнопками
- Самопроверка части 2 (показать ответ и решение)
- Подписка снимает дневные лимиты (оплата - заглушка)
- Админка: статистика и выдача подписки

## Стек 

- Python 3.11
- aiogram 3 (Telegram-бот)
- SQLite
- Docker

## Запуск через Docker

```bash
cp .env.example .env      # впишите BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
```

При первом запуске задания автоматически зальются из `tasks.json`.
Откройте бота в Telegram и нажмите `/start`.

## Как добавить или изменить задания

1. Откройте `tasks.json` и добавьте задание:

```json
{
  "task_number": 5,
  "variant_number": 1,
  "part": 1,
  "question": "Условие задачи",
  "options": ["A", "B", "C", "D"],
  "answer": "B",
  "solution": "Подробное решение"
}
```

- `part: 1` - задание части 1 (с вариантами или коротким ответом)
- `part: 2` - развёрнутое задание (только самопроверка)
- `options` - список вариантов ответа (можно не указывать)
- `solution` - решение, показывается по кнопке

2. Перезалейте задания в базу:

```bash
docker compose exec bot python init_db.py
```

## Админка

- `/admin` - открыть панель (только для ID из `ADMIN_IDS`)
- Статистика - пользователи, подписки, попытки
- Выдать подписку - по Telegram ID пользователя
